Exploratory Data Analysis (EDA)

What is EDA?

  • First step in analyzing data
  • Summarizes main characteristics of datasets
  • Helps detect patterns, outliers, and relationships

Using dplyr for Data Manipulation

# Load the dplyr package
library(dplyr)

# Filter and summarize data
mtcars %>%
    filter(mpg > 20) %>%
    summarise(avg_hp = mean(hp), count = n())
##   avg_hp count
## 1   88.5    14

Visualization with Base R

# Simple scatter plot

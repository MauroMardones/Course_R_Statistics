# R Basic Course  

## Description  

This course is designed for students and professionals interested in learning the fundamentals of R. It covers topics from data manipulation to basic statistical analysis and visualization.  

The content is structured into clear sections to support step-by-step learning and includes additional resources such as presentations and practical exercises.  

## Course Components  

- **[Intro](01-intro.Rmd)**: General course overview and RStudio setup.  
- **[Exploratory Data Analysis (EDA)](02-EDA.Rmd)**: Basic concepts for data exploration.  
- **[Descriptive Statistics](03-Descr-stats.Rmd)**: Essential statistical calculations.  
- **[Visualization and Maps](04-Viz-Maps.Rmd)**: Visualization techniques and map handling.  
- **[Efficient code](05-Effi_code.Rmd)**: Efficient code organization strategies.  
- **[Reporting and Sharing Results](06-Rep_Share.Rmd)**: Report generation and result sharing.  
- **[References](07-references.Rmd)**: Bibliographic sources and additional materials.
